# 🌍 Global Airbnb Performance Analysis Dashboard

## 📌 Project Overview

The Global Airbnb Performance Analysis project focuses on analyzing Airbnb listings across 10 major cities to understand market distribution, host performance, property types, and customer review patterns.

The project uses Microsoft Excel for data preparation and Microsoft Power BI for data visualization and dashboard development.

The main objective is to transform raw Airbnb data into meaningful business insights through interactive dashboards and data-driven analysis.

## 🎯 Project Objectives

- Analyze Airbnb listings across 10 major cities.
- Understand the distribution of different property types.
- Evaluate host verification and profile status.
- Analyze customer reviews and reviewer activity.
- Compare listing distribution across cities.
- Identify important patterns and trends in Airbnb data.

## 📈 Dashboard Features

### 1. Overview Analysis
- Total Airbnb listings and hosts.
- City-wise listing distribution.
- Property type analysis.
- Key performance indicators.

### 2. Host Analysis
- Verified vs. non-verified hosts.
- Host profile picture status.
- Host identity verification analysis.

### 3. Review Analysis
- Total customer reviews.
- Reviewer activity.
- Review distribution and patterns.

### 4. Ratings Analysis
- Analysis of Airbnb listing ratings.
- Comparison of rating patterns.
- Customer feedback insights.

## 🔄 Project Workflow

1. Imported raw Airbnb datasets into Microsoft Excel.
2. Cleaned and prepared the data.
3. Organized datasets for analysis.
4. Imported the prepared data into Power BI.
5. Created DAX measures for KPIs and business metrics.
6. Designed interactive dashboards and visualizations.
7. Analyzed the results to identify meaningful insights.
